# Contributing

## Research quality bar

- Prefer primary sources: specifications, official documentation, source code, release notes.
- Separate documented facts from experiment observations and personal interpretation.
- Pin versions for benchmark or compatibility claims.
- State the tested environment and workload.
- Avoid extrapolating one language/runtime result to the entire ecosystem.
- Never commit secrets.

## Commit style

Examples:

```text
docs(otel): summarize tail sampling trade-offs
lab(collector): add memory limiter experiment
research(datadog): compare DDOT and upstream collector
```
